# Travel Planner App

Travel Planner App is an open-source web application for planning trips, exploring destinations, organizing itineraries, and managing travel budgets.

## Features

- Browse popular travel destinations
- Create simple travel itineraries
- Manage daily trip plans
- Estimate travel budgets
- Save favorite destinations
- Prepare for future API integrations such as weather, maps, hotels, and attractions

## Why this project matters

Travel planning apps often involve user input, third-party APIs, location data, dependency packages, and deployment configurations. This project is designed as a practical open-source example for building a secure and maintainable travel planning web application.

The project will continue to be improved with more features such as destination search, weather information, map integration, and itinerary sharing.

## Security considerations

Because this project uses frontend dependencies and may later connect to external APIs, security and code quality are important. Codex Security can help identify dependency vulnerabilities, unsafe code patterns, insecure API usage, and potential input validation issues.
